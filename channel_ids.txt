# One entry per line: <channel_id> | @handle  [options]
# Handles are resolved to channel IDs at run time (1 YouTube API quota unit).
# Options:
#   digest — bundle this channel's new videos into ONE compact TL;DR message
#            per run (for prolific channels, so the chat isn't flooded)
#   max=N  — per-run video cap for this channel (default: MAX_VIDEOS_PER_RUN,
#            which itself defaults to 0 = no cap). 0 means no cap.
#   only=a,b,c — only process videos whose TITLE mentions one of these keywords
#            (whole-word, case-insensitive; filtered out before any transcript
#            is fetched, so skipped videos cost nothing)
#   lang=xx — the language the channel speaks (ISO 639-1). Only a caption
#            track in that language is accepted; YouTube keeps translated and
#            auto-dubbed tracks beside the original and a provider may serve
#            any of them (Sept 2026: Arabic for English videos, English for
#            German ones). Without it any language in TRANSCRIPT_LANGUAGES
#            (default en,de) passes, so set it wherever the language is known.
#
# No per-run caps are set: every video a channel publishes is processed in the
# run that finds it, rather than trickling out over later runs. Channel order
# still decides who gets served first if the transcript pool runs dry mid-run
# (see README, "Transcript budget"), so the channels you least want to miss
# stay at the top.
